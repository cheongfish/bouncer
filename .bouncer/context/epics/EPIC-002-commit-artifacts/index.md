# EPIC-002 commit-artifacts

Bouncer가 남기는 산출물이 팀의 커밋 규약과 리뷰 관행에 맞도록 만든다.

게이트는 이미 신뢰할 수 있지만, 그 결과로 저장소에 쌓이는 것 — 커밋 메시지와
검증 문서 — 은 아직 다듬어지지 않았다. 팀에 배포되면 이 산출물이 매 커밋마다
누적되므로, 배포 전에 정리한다.

비목표: 게이트 판정 로직 변경, 검증 명령 실행 방식 변경.
