# EPIC-001 cli-usability

`bouncer` CLI를 팀원이 처음 만났을 때 막히지 않게 만든다.

게이트와 문서 계약은 이미 결정적이지만, CLI 자체는 무엇을 할 수 있는지 알려주지
않는다. 배포 대상이 팀으로 넓어지면 이 간극이 첫 사용자의 이탈 지점이 된다.

비목표: 외부 인자 파서 도입, 대화형 프롬프트, 서브커맨드별 상세 매뉴얼.
