# Structures to Avoid (Korean context)

## Binary contrast runway

Do not stage a negation then the real point.

| Pattern | Fix |
| --- | --- |
| `X가 문제가 아닙니다. Y가 문제입니다.` | `문제는 Y다.` |
| `단순히 X가 아니라 Y입니다.` | `Y다.` |
| `~가 아니라, 사실은 ~` | 사실만 적는다 |

## Negation list then reveal

`A가 아니다. B도 아니다. C다.` → `C다.`

## Section that restates itself

A closing paragraph that only repeats Goal / Scope / Checklist above it.
Delete the restatement.

## English overview + Korean body

Opening in English then Korean detail. Write the body in Korean; keep English
only inside code fences or proper nouns.

## Empty passive / abstract subject

| Weak | Stronger |
| --- | --- |
| `변경이 적용된다` | `에이전트가 tasks.md를 고친다` / `훅이 커밋을 막는다` |
| `결정이 도출된다` | `사용자가 affected_paths를 확정한다` |
| `검증이 수행된다` | `execute 게이트가 config.verify를 실행한다` |

## Fake drama / slogan closers

Fragment stacks (`빠름. 정확. 끝.`) and poster lines. Prefer one plain sentence
with the fact.
