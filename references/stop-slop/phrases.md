# Phrases to Remove (Korean context)

## Throat-clearing

Cut these and state the point.

- `다음과 같습니다`
- `아래와 같습니다`
- `중요한 점은`
- `핵심은 바로`
- `살펴보면`
- `다시 말하면`
- `사실상`
- `결국에는`
- `한마디로 말해`
- `여기서 주목할 점은`
- `이 섹션에서는 …를 다룹니다`

## Emphasis crutches

Delete; they add no fact.

- `반드시 기억해야 합니다`
- `절대 간과해서는 안 됩니다`
- `매우 / 정말 / 굉장히` (intensifiers with no measurement)
- `분명히`
- `당연히`

## Softening / padding

- `필요하다고 볼 수 있습니다`
- `고려해 볼 수 있습니다`
- `도움이 될 것입니다`
- `원활한 …를 위해`
- `효과적으로`
- `체계적으로`

## Business / AI jargon (Korean or mixed)

| Avoid | Prefer |
| --- | --- |
| `딥다이브` / deep dive | 원인 분석, 해당 파일 확인 |
| `레버리지` | 재사용, 활용 |
| `얼라인` | 맞추다, 합의하다 |
| `이슈를 네비게이트` | 처리하다, 고치다 |
| `가시성을 확보` | 로그/필드에 남긴다 |
| `임팩트가 큰` | 어떤 게이트/경로가 깨지는지 적는다 |

## Vague declaratives

Replace with a named thing.

- `이유는 구조적입니다` → 어떤 구조(파일·게이트·필드)인지
- `본질적으로는 …입니다` → 구체 문장 하나
- `전반적으로 개선됩니다` → 무엇이 어떻게 바뀌는지
