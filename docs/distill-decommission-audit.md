# Distill 폐기 감사

현재 Distill master와 등록된 일곱 shard의 `Invariants`·`Gotchas`·`Decisions` bullet을
canonical 문서에 연결한 매핑이다. 후속 제거 범위를 승인하는 리뷰 입력이다.
매핑이 없거나 의미가 충돌한 문장은 삭제(`obsolete`)로 넘기지 않았다.
`migrate`가 있으면 해당 canonical 문서 변경을 `/bouncer-plan`으로 승인한 뒤에만
제거를 시작한다.

Distill 입력은 `bouncer project-root`가 가리키는
`${PROJECT_ROOT}/.bouncer/Distill.md`와 `.bouncer/distill/` shard다. 이 감사는
그 원문을 바꾸지 않는다.
